# Changelog

All notable changes to the OfficeX Suite will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0-beta] - 2026-07-12

### Added
- **OfficeX Launcher**: Modern glassmorphism UI for launching applications.
- **OfficeX Settings**: General, Appearance, and Account settings UI.
- **Authentication Module**: Mock authentication using Zustand.
- **Turborepo Integration**: High-speed build system configured for Vite and TypeScript.
- **Architectural Foundation**: 9 core documentation files approved and scaffolded.
- **Shared Libraries**: `ui`, `theme`, `auth` packages created.

### Fixed
- Fixed backend dev script crashing `turbo run dev` due to invalid syntax.
- Fixed duplicated package names to avoid workspace collisions.
